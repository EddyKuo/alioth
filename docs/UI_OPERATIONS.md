## 0. 全域規則（讀懂每一條流程的前提）

### 0.1 沒有「未存檔」這個狀態（ADR-008）

每一次文件修改都**當下寫進磁碟**：註解類走增量附加（檔尾加一段），頁面類走全檔重寫。
所以：

- 「儲存」只是觸發一次自動儲存檢查並在狀態列說「文件的修改已即時寫入磁碟」。
- 「復原」不是回到記憶體裡的舊狀態，而是**把檔案截回原長度**（增量）或**把原始位元組寫回去**（重寫）。
- 「復原所有修改」只能回到**本次開啟時**，回不到更早。
- 「另存新檔」是分岔一份副本；原檔保留所有已寫入的修改。

### 0.2 命令堆疊

所有會改檔案的操作都包成命令（`app/command_stack.h`），≥ 100 步。例外（刻意不進堆疊）：
數位簽署（簽完清空堆疊）、清除所有簽章欄位、移除所有頁面標記、擷取頁面、合併多份文件、
分割文件、重設表單、匯入表單資料、頁面標籤、移除密碼與加密。
**每個頁籤各自一份堆疊**：切到別的文件再切回來，復原步驟還在；關掉頁籤才丟掉。

### 0.3 外部變更守衛（PRD-IO-004）

每一次寫入前比對開檔時的檔案快照。被別的程式改過 → 三選一對話框
「重新載入 / 仍要覆蓋 / 取消」，預設取消。被刪掉 → 提示改用另存新檔。

### 0.4 增量 vs 重寫

| 類型 | 操作 | 對簽章的影響 | 確認對話框 |
|---|---|---|---|
| 增量附加 | 所有註解、回覆、狀態、附件、表單欄位建立、替代文字、頁面標籤、戳記、簽署、塗黑標記 | 既有簽章仍有效（顯示「簽章後有變更」） | 只有外部變更守衛 |
| 全檔重寫 | 插入／刪除／移動／複製／取代／旋轉／裁切／調整尺寸／N 頁併一頁／疊加／正規化／套用塗黑／清除隱藏資訊 | 既有簽章**失效** | `confirmRewrite`：「會重寫整份檔案」＋有簽章時加註 |

縮圖拖曳重排也是重寫，也會先問（拖曳最容易誤觸，所以放開後先把清單還原再問）。

### 0.5 每次寫入後的畫面

寫入完成後文件會被**重新讀取**，但重載與開新檔是兩條不同的路：

- 檢視區停在原來那一頁、維持原來的倍率與捲動位置（頁數變少而目前頁超出範圍時才夾回最後一頁）
- 縮圖清單不重建；只有頁數改變（插入／刪除／擷取）時才整份重來，其餘只重新渲染看得到的那幾張
- 註解清單重掃目前頁附近並更新
- 狀態列頁碼反映的是現在這一頁
- 開啟記錄不會因為一次寫入而多一筆

下文每一條的「結果」都隱含這一段，不再重複。

### 0.6 權限（PRD-SEC-001）

文件的權限旗標會灰化對應動作並在 tooltip 說明原因（灰化以 id 前綴掃描，
所有 `annot.*` 一起處理，新加的註解工具自動被蓋到）；快捷鍵仍可能打到，
所以 `commitAnnotation` 這個唯一入口會再檢查一次。

**沒有開啟文件時**，需要文件的動作一律灰掉——包括快速存取列的儲存與列印。
面板開關不在此列：要先叫得出面板才開得了檔案。

### 0.7 工具持續模式（PRD-UI-007）

預設**關閉**：畫完一則註解自動切回「選取文字」。開啟時停在同一工具。
入口：常用／工具／「工具持續模式」、編輯選單。見 §0.8 的適用範圍。

### 0.8 工具用完之後

走 `commitAnnotation` 的註解工具、塗黑標記、表單欄位在完成一次之後都會切回
「選取文字」（除非開著工具持續模式）。鉛筆是例外——連續筆畫是它的正常用法。

## 1. 檔案分頁

### 1.1 文件群組

| 按鈕 | id | 入口 | 流程 | 結果 |
|---|---|---|---|---|
| 開啟 | `file.open` | Ctrl+O、快速存取列、拖放單一 PDF | 檔案對話框（只列 *.pdf） | 已開著的檔案 → 切到那個頁籤；否則新頁籤 + 載入。載入完成：標題列改檔名、狀態列「第 1 / N 頁」、XFA／JavaScript／簽章提示、縮圖／書籤／註解／導覽面板全部重讀、有簽章時自動驗證。失敗 → 「無法開啟文件」對話框 |
| 關閉 | `file.close` | 檔案選單 | 無對話框 | 關掉**目前頁籤**；還有別的頁籤就切過去，沒有就進空狀態：所有面板清空、標題列復原、復原堆疊清空、狀態列「未開啟文件」。閱讀位置寫進開啟記錄 |
| 最近使用 | `file.recent` | 檔案選單子選單、Ribbon | 清單 + 「清除清單」 | Ribbon 上按下去會彈出同一份清單（選單型按鈕一律 InstantPopup） |
| 文件屬性 | `file.properties` | Ctrl+D | 唯讀對話框 | 檔名、路徑、大小、頁數、PDF 版本、標題／作者／製作程式、是否加密、被拒絕的權限、是否有簽章、XFA／JS 注意事項 |

### 1.2 儲存群組

| 按鈕 | id | 流程 | 結果 |
|---|---|---|---|
| 儲存 | `file.save`（Ctrl+S） | 無 | 觸發自動儲存檢查；狀態列「文件的修改已即時寫入磁碟」。沒開檔時沉默 |
| 另存新檔 | `file.saveAs`（Ctrl+Shift+S） | 存檔對話框（預設 `原名-copy.pdf`） | 複製檔案 → **關掉原檔的頁籤**、切換到新檔（與 Acrobat 一致）→ 狀態列說明原檔保留了先前所有修改 |
| 還原至上次儲存 | `file.revert` | 確認框「將復原本次開啟這份文件之後做的所有修改」 | 逐步 undo 到堆疊空；中途失敗停下並說明已復原幾步 |
| 重新命名 | `file.rename` | 輸入新檔名（不含副檔名） | 同資料夾已有同名 → 拒絕（不提供覆蓋）；成功 → 磁碟改名、關舊頁籤、開新路徑 |

### 1.3 輸出群組

| 按鈕 | id | 前置 | 流程 | 結果 |
|---|---|---|---|---|
| 列印 | `file.print`（Ctrl+P） | 需文件；權限 print | 系統列印對話框 → 進度對話框（超過 0.5 秒才出現，可取消） | 逐張列印（含註解），每印完一張更新進度並讓介面回應；取消會在當前這張之後停止並說明已送出幾張 |

| 匯出影像 | `file.exportImage` | 權限 copy | DPI（36–1200，預設 150）→ 存檔對話框（PNG／JPEG／TIFF，依外掛可用性列出） | 只匯出**目前頁**；格式依所選篩選器不依副檔名；狀態列含 KB 數 |

### 1.6 工作階段群組

| 按鈕 | id | 狀態 |
|---|---|---|

## 2. 常用分頁

### 2.1 剪貼簿

| 按鈕 | id | 作用對象 | 行為 |
|---|---|---|---|
| 複製 | `edit.copy`（Ctrl+C，焦點在檢視區） | 選取的**文字** | 純文字 + HTML（保住換行）進剪貼簿；沒選取 → 狀態列「沒有選取任何文字」；權限 copy 擋 |
| 複製註解 | `comment.copy`（編輯選單；Ctrl+C 僅在清單有焦點時） | 頁面上選取的那一則，沒有才看清單目前列 | 以 XFDF mime 進剪貼簿 |
| 剪下 | `edit.cut`（Ctrl+X） | 頁面上選取的那一則，沒有才看清單目前列 | 複製該則（XFDF mime）後刪除。判斷與 Delete 一致 |
| 貼上 | `edit.paste`（Ctrl+V） | 剪貼簿裡的註解 | 貼到**目前頁**；同頁貼上會偏移一點，跨頁以左上角換算；新的 /NM；剪貼簿不是註解時沉默 |
| 全選 | `edit.selectAll`（Ctrl+A） | 目前頁的文字 | 選取整頁文字 |

注意：焦點在**註解清單**時，Ctrl+C／Ctrl+V／Delete 是清單自己的動作（複製註解／貼上註解／刪除註解）；
焦點在**檢視區**時 Ctrl+C 是複製文字、Delete 是刪除頁面上選取的註解（需「選取註解」工具）。

### 2.2 工具（互斥，一次只有一個）

| 工具 | id／鍵 | 游標 | 按下 | 拖曳 | 放開 | 雙擊 |

## 3. 檢視分頁

### 3.1 縮放（範圍 8%–6400%，每步 ×1.25，錨定在視窗中心；停止 80 毫秒後以精確倍率重算）

## 9. 停靠面板（預設只開縮圖；其餘從檢視分頁叫出）

### 9.1 縮圖（左，預設開）

- 每頁一格（固定 160×232，紙張最大 144×192，依長寬比內縮）；未載入的格子是空白紙。
- 只要求看得到的那幾張 + 前後 8 張；捲動補要。
- 點任一處跳頁（含已選取那一格）；方向鍵移動即跳頁；Enter 跳頁。
- 捲動檢視區換頁時選取跟著走並捲進視野。
- 拖曳一格到別處 = 移動頁面：放開後先把清單還原成檔案目前的樣子，再問「會重寫整份檔案」（有簽章時加註失效）；取消就什麼都不做。權限不允許重組時拖放關閉。
- 關檔清空。

### 9.2 書籤（左，與縮圖同疊）

文件 /Outlines 樹，預設展開一層；點擊或 Enter 跳頁；右鍵全部展開／收合。無編輯。

### 9.3 開啟記錄（左）

最近 N 份文件（標題、相對時間、找不到檔案時灰化並標示）；子項是閱讀標記。
Enter：文件 → 開啟並回到上次頁碼與倍率；標記 → 跳到那一頁（已經開著的文件直接跳）。
Delete／右鍵：從記錄移除。搜尋框過濾標題與路徑。

### 9.4 命名目標（左）

/Dests 與 /Names 清單（名稱、位置描述）；壞掉的灰化；搜尋過濾；Enter 跳頁。

### 9.5 連結（左）

目前頁的連結（類型、目標；外部網址完整顯示）；只在面板可見時跟著翻頁；Enter 走與頁面點擊同一條確認流程。

### 9.6 圖層（左）

/OCProperties 樹，可勾選但**畫面不會變**（ADR-003，面板上有說明）；互斥群組連動。

### 9.7 簽章（左）

摘要（全部有效／幾個無法確認／幾個無效，以最壞為準）+ 每個簽章的狀態（文字 + 對比合格的顏色）、findings、涵蓋範圍（部分涵蓋警告）、簽署時間。

### 9.8 標籤／閱讀順序／無障礙檢查器（左／左／右）

- 標籤：結構樹（型別中文 + 原名、頁、替代文字／「缺少替代文字」）；Enter 跳頁；右鍵「設定替代文字」（走命令堆疊，增量寫入）。
- 閱讀順序：目前頁的結構序 vs 內容序比對，標示「順序不一致」。
- 檢查器：依檢查項目分組的缺陷（tooltip 有怎麼修）+ 涵蓋範圍與限制；Enter 跳頁。

### 9.9 搜尋（右）

輸入框 Enter 開始；「區分大小寫」「全字比對」兩個核取方塊（改動即重跑，避免清單與勾選狀態說兩件事）；
結果逐頁進來「第 N 頁：上下文」；點一列 → 選取該命中並跳頁；狀態列顯示索引進度與結果數。

### 9.10 註解（右）

篩選列（作者／類型／排序：頁碼、作者、類型、日期）+ 文字搜尋 + 清單（可多選）。
單擊 → 頁面虛線框 + 跳頁 + 屬性面板顯示那一則；雙擊 → 註釋視窗；右鍵／快捷鍵：複製、貼上、回覆、設定狀態、刪除。
篩掉全部時顯示「目前的篩選條件沒有符合的註解」。內容涵蓋已掃描過的頁面（見 §2.2）。

### 9.11 註解屬性（右）

Ctrl+' 或 Ribbon「註解屬性」叫出。選一則註解（清單或「選取註解」工具）之後顯示它的
顏色、填色、不透明度、線寬、線型、行距與縮排（只對文字框家族顯示）、作者、主旨、內容、
鎖定／隱藏／列印旗標。改任一項即寫回檔案，走命令堆疊可復原。

三件值得知道的事：

- **面板收起來時不讀檔**。讀的是整份文件，而多數時候沒人在看這個面板；打開的當下會補讀一次。
- 寫回沿用原本的**物件編號**並重新產生 /AP：換編號會讓既有回覆的 /IRT 指向孤兒，
  不換 /AP 則會讓字典裡的顏色與畫面上的顏色不一致（Acrobat 以 /AP 為準）。
- **回覆註解會被拒絕**並說明理由——它的 /IRT 與審閱狀態掛在自己的字典上，
  重建字典帶不回那些鍵。要改回覆的文字請用註釋視窗。

### 9.12 欄位（右）

欄位樹（名稱、類型・唯讀・必填・控制項數、頁）、搜尋、「只顯示本頁欄位」（跟著目前頁走）；Enter 跳頁。

### 9.13 附件（右）

文件層與註解附件（檔名、大小、來源）；Enter 或按鈕 = **另存**，不開啟。

### 9.14 Pan & Zoom（右）

目前頁縮圖 + 可視範圍框；拖曳或方向鍵／PgUp／PgDn／Home 移動主視圖。

### 9.15 放大鏡（右）

跟著檢視區游標，顯示該處放大影像（倍率 1.5–8，目前沒有調整入口）。

（先前這裡有一個叫「屬性」的空面板，沒有任何入口到得了它，已移除。文件屬性走 Ctrl+D 的對話框。）

F6／Shift+F6 在檢視區與可見面板之間循環（依畫面位置排序）。

## 10. 狀態列

左：頁碼「第 N / M 頁」（未開檔「未開啟文件」）。右：相容性提示（XFA／JavaScript／含簽章）、
頁面尺寸 mm 與游標 pt 座標（尺寸未知時「尺寸載入中」）、**可輸入的縮放下拉**
（12 個常用倍率，也可以直接打「150」或「150%」；打錯會退回目前倍率而不是縮到 8%）。
中間的臨時訊息是每個動作的主要回饋（3–10 秒）。
